# 職務経歴書

## 職務要約

「より多くの人ができる限り困らない状態」を目指し、デザイン業務に従事しています。  
現在は**デザインシステム構築、プロダクト横断のUI改善、ユーザーリサーチ、アクセシビリティ推進**を中心に業務を行っています。  
事業会社におけるプロダクト開発のスピード感を意識しながら、開発と連携し、より使いやすいデザインを実現するために取り組んでいます。  
また、**生成AIの活用、情報設計の最適化、リサーチを通じたUX向上**にも積極的に取り組んでいます。

---

## 強み

### **プロダクト横断の設計力**
- デザインシステムの統合と運用最適化
- プロダクト間で一貫したUIを提供するためのルール策定と推進
- 情報設計の最適化によるユーザー体験の向上

### **リサーチを活かしたUX改善**
- ユーザー調査（定性・定量）を通じた課題発見と改善策の立案
- 既存機能の使い勝手を評価し、ユーザーインサイトを活かした改善を推進

### **アクセシビリティ推進の実績**
- 国・民間のWebサイトにおけるアクセシビリティチェックと提案（STYZ）
- 社内のデザイン・開発チームへのアクセシビリティ啓発活動
- WCAG準拠を意識したUIデザインと改善

### **生産性向上**
- 業務フローの見直し、AIの活用

## 業務スキル

### **デザインシステム構築・運用**
- デザインシステムの設計・運用と導入
- スタイルガイドの作成・ルール策定
- 開発チームとの連携による実装支援
- プロダクト横断での統合・最適化

### **アクセシビリティ対応**
- Webアクセシビリティチェックと改善提案
- ガイドライン策定、開発チームとの連携
- 社内のアクセシビリティ啓発・研修実施

### **リサーチ & UX改善**
- ユーザーリサーチの企画・実施・分析
- 定量データを活用したUIの改善提案
- 情報設計の見直しによるUX向上
- ユーザーインタビューの設計・実施
- ユーザビリティテストの計画・実行

### **チームサポート**
- ミーティングの進行・調整、アジェンダ作成
- タスクの優先順位付けと進捗管理
- チームメンバーの目標設定リードとフィードバック
